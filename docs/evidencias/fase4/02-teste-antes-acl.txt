4. DIAGNÓSTICO TÉCNICO:
Resultado obtido: ALCANCOU
Causa: O kernel do host Linux atua como roteador entre as duas bridges virtuais
gerenciadas pelo LXD (net-prod com gateway 10.10.10.1 e net-dev com gateway 10.10.20.1).
Como o encaminhamento de pacotes IPv4 (ip_forward) está ativo no host para permitir
o NAT de saída para a internet, os pacotes originados na sub-rede 10.10.20.0/24 são
automaticamente roteados para a sub-rede 10.10.10.0/24.

Impacto de segurança: Um desenvolvedor ou aplicação na rede de desenvolvimento (DEV)
consegue alcançar diretamente a porta 3306 do banco de produção (PROD), violando o
princípio de isolamento entre ambientes e expondo dados sensíveis.

Ação necessária: Criar e aplicar ACLs de rede no LXD (Fase 4.3) descartando o tráfego
cruzado (drop) entre as duas sub-redes.
