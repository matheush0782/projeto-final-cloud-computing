# NOTA DE SEGURANÇA SOBRE A PORTA 8443:
# A porta 8443 NÃO é o WordPress e NÃO é evidência de HTTPS da aplicação.
# Trata-se da API administrativa do LXD (configurada na Fase 5.1).
# O acesso requer autenticação mútua com certificados autorizados (lxc config trust add).
# Em ambientes de produção, recomenda-se restringir esta porta ao loopback (127.0.0.1:8443)
# ou a uma VLAN isolada de administração, prevenindo acesso não autorizado ao daemon.
